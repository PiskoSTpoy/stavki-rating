Как перевести американские и дробные коэффициенты в десятичные?

Алексей Камнев·опубликовано 15.11.2026·обновлено 15.11.2026·факты проверены 15.11.2026·6 мин чтения

Дробный коэффициент переводится в десятичный по формуле «числитель / знаменатель + 1», американский — по двум формулам: при плюсе «число / 100 + 1», при минусе «100 / число + 1». Так 3/2 и +150 дают 2,50, а 1/4 и −400 — 1,25. Десятичный формат, принятый в России, сразу показывает общую выплату на единицу ставки.

Чем различаются три формата записи

Десятичный коэффициент показывает полную выплату на единицу ставки, дробный — чистую прибыль к ставке, американский — прибыль со 100 единиц (плюс) или ставку, нужную для прибыли в 100 (минус). По Wikipedia, это три принятых способа записи коэффициентов, различающихся только упаковкой одной и той же цены. На российском рынке почти повсеместно используется десятичный формат, а остальные встречаются в зарубежных обзорах и на международных площадках, поэтому для сравнения линий их нужно уметь пересчитывать.

Как перевести дробный коэффициент

Дробный коэффициент a/b означает прибыль a при ставке b, поэтому десятичное значение равно a/b + 1. Для 3/2 получаем 1,5 + 1 = 2,50, для 1/4 — 0,25 + 1 = 1,25, для 5/1 — 6,00. Обратный пересчёт: десятичный минус единица, затем дробь сокращается, например 1,80 − 1 = 0,80 = 4/5. Записи вроде «evens» (1/1) соответствуют 2,00, то есть вероятности 50%.

Как перевести американский коэффициент

Американский коэффициент со знаком плюс показывает прибыль со ставки 100: +150 означает прибыль 150 со 100, то есть десятичный коэффициент 150/100 + 1 = 2,50. Со знаком минус показывает ставку, нужную для прибыли 100: −200 значит ставка 200 ради прибыли 100, то есть 100/200 + 1 = 1,50. Обратный пересчёт для десятичного d: при d ≥ 2 американский = (d − 1) × 100 со знаком плюс, при d < 2 — минус 100 / (d − 1).

Как получить вероятность из любого формата

Сначала формат переводится в десятичный, затем вероятность равна 1/к. Для +150 это 1/2,50 = 40%, для −200 — 1/1,50 = 66,7%, для 3/2 — 40%. Сумма таких вероятностей по всем исходам события превышает 100% на величину маржи БК; как её убрать, показано в материале про снятие маржи. Чтобы не считать вручную, подходит конвертер коэффициентов.

Типичные ошибки при пересчёте

Типичная ошибка — забыть прибавить единицу к дробному коэффициенту и принять 3/2 за 1,50 вместо 2,50. Вторая — перепутать знаки американской записи: плюс означает прибыль со 100, а минус — ставку ради 100, и поэтому минус всегда указывает на фаворита. Третья — сравнивать линии разных БК без учёта разной маржи: одинаковые коэффициенты не означают одинаковой вероятности. Основы чтения коэффициентов — в материале про коэффициенты.

Частые вопросы

Как перевести +200 в десятичный коэффициент?

200/100 + 1 = 3,00.

Как перевести −150 в десятичный коэффициент?

100/150 + 1 = 1,67 (округлённо).

Что значит дробный коэффициент 7/4?

Прибыль 7 со ставки 4; десятичный — 7/4 + 1 = 2,75.

Почему в России используют десятичные коэффициенты?

Они показывают итоговую выплату на единицу ставки без дополнительных вычислений.
